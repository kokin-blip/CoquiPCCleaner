## First functional implementation batch

Coqui's source now has a pure `scan_review` query with generated Rust/TypeScript types. It summarizes exact retained file-only cache/development categories, limited startup observations, separately dated retained application observations, and indexed files with **at least 1 GiB allocated**. This is Coqui's explicit large-file threshold, not an inferred CleanMyMac threshold. Missing observations remain nullable; partial scans remain partial. The query does not collect, contact a service, refresh applications, inspect Git, write history or authorize removal.

The Overview tiles consume these measurements and open focused cache/startup/application/storage reviews. “What was checked” discloses source dates, measurement states and qualifications. Cleanup starts in Cache files. Developer files, Build & test trials and Workload advice have secondary More tools shortcuts; detailed hardware/firmware/maintenance routes remain there. Existing cache/project/duplicate/portable-removal policies remain intact, with empty removal selections.

This batch does **not** implement a combined execution queue, app-update discovery/installation, Downloads-scoped content analysis, broad system-junk removal or automatic system maintenance. The native whole-disk scan's missing foreground snapshot is disclosed rather than repaired by a silent background collection. Further parity work must address these separately; no whole-product parity or new installed release is claimed.
