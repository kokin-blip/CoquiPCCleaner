# Release roadmap

1. **Phase 1 — System Scanner:** reliable read-only Apple Silicon macOS scanner, responsive native-inspired Tauri/Svelte UI, local history, permissions, available hardware/security information and storage exploration. Acceptance: real scan/cancel/inspect/reopen/purge flows and honest capability reporting.
2. **Phase 2 — Optimization Engine:** milestones 2.1–2.3 (cache/project approval and Git/worktree review) and 2.4 (local investigations, duplicates, baselines/manual plans, advice, app-open maintenance and qualified resource review) are implemented within documented capability bounds; see phases/phase-2-progress.md for validation and remaining work, and phases/phase-2.md for the full specification. See phases/phase-2-workflows.md for supported operations and retained extensions; external AI is absent by user choice, and application-native resources/unsupported system changes stay manual.
3. **Phase 3 — Advanced Firmware Diagnostics:** see phases/phase-3.md. Milestone 3.1 implements opt-in Apple Silicon inventory/security audits, explicitly consented macOS update listings and separate Apple manual guidance. See phases/phase-3-implementation.md for the actual compatibility matrix, freshness and validation. Milestone 3.2 (0.7.0) completes the remaining supported macOS review workflows: saved-audit comparisons, in-app evidence notices, default-off app-open reminders and linked manual follow-up evidence. See phases/phase-3-completion.md for acceptance and explicit limits. Firmware mutation is not implemented; any later supported mutation requires its own tested, separately authorized workflow.
4. **Windows:** see phases/windows.md. Starts only after the first completed macOS build; shares domains and UI while using its own system adapter and permissions.
5. **Intel Macs:** see phases/intel.md. A separate compatibility and validation effort, not an untested universal-release claim.

All original feature and UX requirements remain in ../docs/original-brief.md. Deferred functionality must not appear as working controls in Phase 1.
