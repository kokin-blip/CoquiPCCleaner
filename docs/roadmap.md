# Release roadmap

1. **Phase 1 — System Scanner:** reliable read-only Apple Silicon macOS scanner, responsive native-inspired Tauri/Svelte UI, local history, permissions, available hardware/security information and storage exploration. Acceptance: real scan/cancel/inspect/reopen/purge flows and honest capability reporting.
2. **Phase 2 — Optimization Engine:** milestone 2.1 (cleanup approval/verification) is implemented; see phases/phase-2-progress.md for validation and remaining work, and phases/phase-2.md for the full specification. Add separately reviewed actions, AI explanations grounded in typed evidence, developer storage, duplication analysis, supported adjustments and measured verification.
3. **Phase 3 — Advanced Firmware Diagnostics:** see phases/phase-3.md. Optional model-specific audits and manual guidance; any supported firmware mutation remains a separate authorized workflow.
4. **Windows:** see phases/windows.md. Starts only after the first completed macOS build; shares domains and UI while using its own system adapter and permissions.
5. **Intel Macs:** see phases/intel.md. A separate compatibility and validation effort, not an untested universal-release claim.

All original feature and UX requirements remain in ../docs/original-brief.md. Deferred functionality must not appear as working controls in Phase 1.
