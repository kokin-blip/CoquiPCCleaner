REA inspected the user-selected local AppCleaner 3.6.8 (build 4332) and CleanMyMac 5.2.4 App Store edition. Sources were packaged metadata, localized feature declarations, Interface Builder connections and visible interfaces. Deep decompilation providers were unavailable.
