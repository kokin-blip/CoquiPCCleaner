# CoquiPCCleaner 0.13.0

macOS-only release for **Apple Silicon (arm64), macOS 14 or later**.

## Highlights

- Simpler mint/frog interface with five main destinations, an explicit Scan Mac start and separately reopened saved results.
- Per-scan system, startup and application metadata choices, independently dated results and explicit partial/unavailable states.
- Twelve broader Cleanup categories with file-only indexed footprints and paginated exact-path inspection. Cache selections start empty and enter the existing fresh review; logs, archives, device/simulator data, backups and system locations remain manual or protected.
- Downloads-scoped exact-copy analysis, retained path/age filters and separately selected PNG/JPEG similarity analysis. Keeper checks and separate removal approval remain mandatory.
- Opt-in application update discovery with dated sources and installation through the vendor or App Store.
- Development-storage indicators, local Git evidence, user-operated build/test trials, local Ask Coqui, recommendation plans and dated advice references.
- Whole-disk traversal/import reliability and large-index folder browsing improvements, with access omissions retained explicitly.

## Downloads and installation

- `CoquiPCCleaner-0.13.0-macOS-arm64.zip`: portable application. Extract and move the app to Applications for ordinary use.
- `CoquiPCCleaner-0.13.0-administrator-arm64.pkg`: optional matching app-plus-helper installer. Use this package when upgrading an existing helper installation; portable and helper binaries from different builds cannot authenticate together.
- `SHA256SUMS`: checksums for both macOS artifacts.

The application/helper use local ad hoc signatures and are **not Developer ID signed or notarized**. Downloaded Gatekeeper behavior is not validated; macOS may require explicit user approval. Installer authentication and any Full Disk Access approval are user-operated and separate from app review/cleanup authority. The package preserves settings/history and does not enable administrator features by default. Installation of this release on the development Mac is not part of publication.

## Validation and limits

The release checkpoint and exact artifact hashes are recorded in [status](../status.md). Source tests, native disposable fixtures, retained-index browsing, payload architecture/signature/pairing checks and packaging are distinct from installed matching-build acceptance. No test removes existing user files. The previously validated whole-disk run remains partial, including 26 system/service permission denials, deliberate omissions and live-filesystem races; it is not comprehensive access or guaranteed recoverable capacity.

Removal selections remain empty, every supported action requires its existing fresh review/approval, and Coqui never empties Trash. System maintenance stays guided/manual, update installation stays vendor-managed and Ask Coqui stays local. Custom/app-specific cleanup coverage, modern managed login coverage, photo-quality grouping, full VoiceOver, other Macs/macOS versions and the new installed administrator orchestration remain unverified or open. See [the continuation ledger](../phases/cleanmymac-workflow.md).

No Windows or Intel build is included.
