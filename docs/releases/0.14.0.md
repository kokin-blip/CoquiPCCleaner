# CoquiPCCleaner 0.14.0

macOS-only release for **Apple Silicon (arm64), macOS 14 or later**.

Published as [GitHub Latest](https://github.com/kokin-blip/CoquiPCCleaner/releases/tag/v0.14.0) on 2026-10-30 from source commit [`0aa64b1`](https://github.com/kokin-blip/CoquiPCCleaner/commit/0aa64b1dfc56615429e4bc4fde824f9ab732726b); the `v0.14.0` tag stays on that release source.

## Highlights

- Guided Cleanup: choose cache groups/files → fresh review → one explicit Trash approval → per-file results.
- **Select all cache groups**, **Select all in this group**, page selection and individual exceptions work across all pages. Categories and Cache files share selection, with a sticky selected-count/allocation summary.
- Cancellable disk-backed selection and fresh checks support large indexes without the previous 100-file review cap. A 250,001-file indexed fixture selected without truncation; this is not a 250,001-file native removal test.
- Frozen review shows eligible/refused groups, reasons and paginated exact paths. Two unchecked acknowledgements and a ten-minute single-use approval remain separate from selection. Each move repeats fresh checks, journals intent and verifies the Trash result.
- Action history follows active bulk outcomes, including read-only refresh after transport loss. Cancellation, interruption and uncertain moves never resume or retry automatically.
- Existing project/duplicate reviews, manual/protected categories, local Ask, developer/task tools, More tools, vendor-managed updates and manual maintenance remain available.

Only currently supported individual user/Xcode cache files can enter bulk execution. Namespace grouping adds no folder-removal authority. Logs, archives, device/simulator data, backups, Trash and system/shared locations keep their manual/protected boundaries. Indexed or reviewed allocation is not promised reclaimed space; Coqui never empties Trash.

## Downloads and installation

- `CoquiPCCleaner-0.14.0-macOS-arm64.zip`: portable application. Extract and move the app to Applications for ordinary use.
- `CoquiPCCleaner-0.14.0-administrator-arm64.pkg`: optional matching app-plus-helper installer. Use this package when upgrading an existing helper installation; different-build app/helper binaries cannot authenticate together.
- `SHA256SUMS`: SHA-256 checksums for both macOS artifacts.

**Database compatibility:** schema 8 preserves existing settings/history and adds bulk-cache journals. Older schema-7 binaries, including 0.13.0, cannot reopen a database upgraded by 0.14.0. Reverting the application alone does not downgrade its database. Packaging/publication does not upgrade the development Mac's installed application or database.

The app/helper are locally ad hoc signed and **not Developer ID signed or notarized**. Downloaded Gatekeeper behavior remains unvalidated; macOS may require explicit user approval. Installer authentication and any privacy approval are user-operated and separate from cleanup authority. Administrator mode remains default-off. No new helper protocol or privilege expansion is included.

## Validation and limits

Source validation passed the production frontend build, 128 UI tests, 220 Rust tests with 9 intentionally ignored, formatting and Tauri cargo check. A separately selected native macOS fixture moved two newly created disposable files through Foundation Trash, verified them and restored them immediately. Native WebKit light/dark fixture layouts were inspected at normal and minimum sizes. No existing user file was used for removal testing.

Exact final build/signature/package checks, artifact hashes and publication verification are recorded in [status](../status.md). Those checks remain distinct from installed matching-build/native bridge/helper acceptance, full VoiceOver, other Macs/macOS versions and large real-file native bulk execution. The known pathname-race and Trash-dependent recovery limits remain. Earlier permission denials, deliberate omissions and live-filesystem qualifications remain partial coverage, not comprehensive access. See [the guided-cleanup contract](../phases/guided-cleanup.md) and [continuation ledger](../phases/cleanmymac-workflow.md).

No Windows or Intel build is included.
