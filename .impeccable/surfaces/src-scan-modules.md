# Selected scan checks

Mode: Operate. Make a user-initiated scan explicit about storage scope and optional foreground metadata, then let the owner review the dated evidence.

## Direction contract

THESIS: Scan storage plus selected metadata checks; distinguish each collected, skipped or incomplete result. Saved browsing never starts collection.

OWN-WORLD: Ordinary extension of Coqui's approved native macOS composition: charcoal/light surfaces, system type, mint action, line icons and existing frog. No new artwork or token system.

STORY: The existing scope review gains three additional metadata choices. Storage remains the configured scope; the optional choices disclose standard system/startup/Applications locations and honor exclusions. Results retain independent dates/statuses and links to explicit separate content/network tools. Removal selections remain empty.

FIRST VIEWPORT: One start action. Protected scope/check review uses the existing focused dialog and primary scan action. Results preserve the four overview destinations; per-check evidence lives under What was checked and in History. Startup detail reads the matching scan's record.

FORM: Code-led extension of the pinned native system. No replacement world or comp applies.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Keep vendor-managed update installation, manual maintenance, local Ask Coqui, secondary developer/trial tools, existing privacy grants and partial coverage. No runtime-enabled/login-coverage or full-disk-completeness claim follows from these checks.
